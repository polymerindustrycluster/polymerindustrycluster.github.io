How to trust this

Reproduce it. Each analysis publishes the API endpoint, the exact filter values, and the fetch script. Run the script and you get the same bytes we did.

Falsify it. Every published sentence is backed by an assertion that re-runs against the data that produced it, with a stated condition that would make it wrong.

Argue with it. Found an error? Open an issue on the repository. Corrections are dated and public — silent edits are forbidden by our own methods policy.
